Optional custom UI font
=======================

By default Replayr uses fonts that ship with Windows:
  - Segoe UI / Segoe UI Semibold for text
  - Segoe Fluent Icons (Windows 11) or Segoe MDL2 Assets (Windows 10) for icons

To use Inter instead, drop these two files in this folder and rebuild
(the build copies this folder next to Replayr.exe):

  Inter-Regular.ttf
  Inter-SemiBold.ttf

Inter is free (SIL Open Font License): https://rsms.me/inter/
